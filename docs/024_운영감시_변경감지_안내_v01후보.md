# 024 운영 감시·변경 감지 안내 v01후보 (2026-11-03, work 가지)

운영 main 미반영. 대표 승인 뒤 기본 가지에 반영되면 아래가 자동으로 돈다.

## 무엇이 추가됐나
| 파일 | 역할 |
|---|---|
| `tools/change_rules.json` | 파일별 기록 키·의미(meaning) 필드·단순(simple) 필드·추가/삭제 정책·파일 보류 비율. `preapproval.approved_by` 가 비어 있으면 "규칙 초안" |
| `tools/change_guard.py` | 새 수집본 ↔ 직전 공개본 기록 단위 비교. 의미 변경·삭제는 직전본 값으로 되돌려 공개(재검증 대기), 단순 갱신·추가는 공개. 기록: `review/<구>/_reverify.json`(대기), `ops/changes/<구>.json`(변경 전후·출처·확인일·지역) |
| `tools/gate.py` v06 | 검문 안에서 change_guard 호출, `_status.json` 에 `change_check`·`reverify_pending`·`updated` 기록, 서울·경기(`tools/safety_policy.json`) 공개 거부 |
| `approvals/reverify.json` | 대표·피트가 원문 대조 뒤 승인을 적는 곳(형식은 파일 안 `_예시`) |
| `tools/monitor.py` + `.github/workflows/monitor.yml` | 매시간: 장애 / 검증 필요 / 공개 보류 / 복구 완료 → `ops/monitor.json`, `ops/incidents_log.json`. 외부 공공 API 0회 |
| `tools/safety_policy.json` | 모든 운영 지역 공통 기준, 서울·경기 제외, 작업 예상 간격, 앱이 읽는 가지 |
| `tools/api_budget.json` | 출처별 하루·주간 호출 추정, 낭비 지점, 무료 범위 |
| airang-stats `admin/index.html` 상태판 | 위 monitor.json 을 읽어 네 칸으로 표시(감시 전이면 "감시 미적용") |

## 재검증 승인 절차(사람)
1. 관리자 상태판 '검증 필요' 또는 `review/<구>/_reverify.json` 에서 항목 확인(before/after·source_url·first_seen).
2. 원문(심평원·E-Gen·복지로·나이스)과 대조.
3. `approvals/reverify.json` 의 `items` 에 `{city, file, key, approved_at, by, note}` 추가(여러 건이면 `key:"*"` + `all_pending_before`).
4. 다음 수집(daily 05:30 / hospitals 월요일)에서 새 값이 공개되고 `ops/changes/<구>.json` 에 '적용(승인 반영)'으로 남는다.

## 상태 뜻
- **장애**: 작업 실패·누락, 올리기(push)·배포 실패, 사이트 응답 오류, `_status.json` 못 읽음, 브랜치 지연(앱이 읽는 main 이 기본 가지보다 오래됨), 자료 만료, 검문 멈춤, 정책 위반(서울·경기)
- **검증 필요**: 자동 검사 실패·만료, 의미 변경 과다(파일 보류), 지역 섞임 의심, 재검증 대기, 공개 중·원문 부분 확인
- **공개 보류**: 원문 미확인으로 숨긴 자료(급식·특목·날씨)
- **복구 완료**: 직전 집계에 있던 장애·검증 필요가 사라짐(감시가 `ops/incidents_log.json` 에 자동 기록). 사람이 적는 복구 이력은 `ops/recovery_log.json`

## 한계(솔직하게)
- 공식 정보 변경의 '감지 속도' = 수집 주기(학교·학원 매일, 병원·혜택 주 1회). 별도 폴링은 API 한도 때문에 넣지 않음.
- 자동 수집 성공(auto_check)과 기관 원문 검증(official_verify)은 별개 — 전자는 기계, 후자는 사람 표본 대조. monitor.json 의 `cities.<구>.auto_pass / official_done / official_partial` 로 구분.
- change_guard 는 기록 키가 같은 것만 비교한다. 이름·주소가 동시에 바뀐 의원은 '삭제+추가'로 보인다(삭제는 보류, 추가는 공개).
