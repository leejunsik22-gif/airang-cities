# 022-1 확장지역(대구·부산·제주·청주·충주) 공식 코드 검증표 _v01후보

- 작성: 2026-11-03, 클로드(아이랑대전 022). **후보/검수 전** 문서. 실제 API 키로 호출 검증은 미실시(키 없음).
- 검증 상태 기준: **확인** = 기관 원문(코드표·공식 문서·실호출 응답)에서 값을 직접 읽음 / **확인(간접)** = 원문 코드 체계로부터 1단계 유도 / **미확인** = 원문 접근 불가 또는 산출값.
- 집계: 확인 267건, 미확인 109건 (시·도표 4행×6항목=24칸 + 구·군표 32행×11항목=352칸, 총 376칸 기준).

## 핵심 발견 (대전 기존 설정값과 다른 점)
1. **심평원 sgguCd는 법정동 코드가 아님.** HIRA 자체 "지역코드" 6자리(예: 대전 유성구 = **250001**, 대구 중구 = **230006**, 부산 중구 = **210008**). 질문의 "유성구 250040?"은 정보나루 dtl_region(25040)과 혼동된 값으로 보임 → 대전 설정도 재점검 필요.
2. **심평원 sidoCd 부산은 210000** (법정동 26이 아님). 대구 230000, 제주 390000, 충북 330000.
3. **관광공사 TourAPI areaCode/sigunguCode는 "미사용 기능(삭제예정)"**으로 공지됨(법정동 시도·시군구 코드 lDongRegnCd/lDongSignguCd로 대체, ldongCode2 신설). 기존 sigunguCode 표를 웹에서 공식 원문으로 확보하지 못해 전부 **미확인**. 신규 구현은 법정동 기반 파라미터 사용 권장.
4. **대구 군위군**(2023-07-01 편입)은 법정동 27720, HIRA 230200, 정보나루 22520 모두 현행 코드 존재 → 포함 가능. 단 KOPIS 공통코드 PDF에는 경북 4772로만 수록(갱신 지연).
5. 청주시 4개 구: 법정동 43111~43114, HIRA 330101(상당)/330104(서원)/330102(흥덕)/330103(청원) — **순서가 법정동과 다름**. 정보나루 33041~33044. KOPIS는 청주시(4311) 단위만 존재.
6. 기상청 nx,ny는 공식 엑셀을 열 수 없어(격자_위경도 xlsx 다운로드 차단) **기상청 공개 변환식(LCC)으로 구·군청 좌표에서 산출** → 전부 미확인. 경계 격자(대구 동구·서구, 부산 동구, 서귀포, 청주 흥덕구, 충주)는 ±1 차이 가능성 있어 엑셀 대조 필수.

6. 군위군 포함 여부는 대표 결정 사항(코드는 모두 준비됨).
