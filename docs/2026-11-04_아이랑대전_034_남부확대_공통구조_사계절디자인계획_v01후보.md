## 2. 공통 구조(재사용 — 새 코드 없음)
- 도시 추가 = `regions/<시도>.json` + `app/cities_candidates/<시도>.json` + `app/themes/<시도>.json` 3파일. 앱 코드(`app/index.html`)·수집기·검문(gate)·관리자는 그대로.
- 공개 흐름: `newcity.yml`(staging만) → `gate --dry-run`·`check_region` → 공식 원문 대조(사람) → 대표 승인 → `publish-city.yml`(대표 계정 + "승인") → `data/<도시>/`. 미확인 코드 수집기는 `tools/allowed_scripts.py`가 자동 차단.
- 자료 분리: 도시마다 `data/<도시>/`·`review/<도시>/`·`staging/<도시>/` 따로. 지역 섞임은 `check_region.py`가 격리.

## 3. v3 장면 사진 — 시·도별 + 계절별 폴더 규칙(제안, 코드 변경은 승인 뒤)
```
app/scenes/common/<장면>-{m,w}.webp                 ← 대전에서 만든 10장면(033) = 기본값
app/scenes/<시도태그>/<장면>-{m,w}.webp              ← 지역 특색(예: busan/home-m.webp 해운대 원경 실루엣)
app/scenes/<시도태그>/<장면>-<season>-{m,w}.webp     ← 계절(spring/summer/autumn/winter)
```
- 빌드 규칙(추가 예정): 도시의 시·도 폴더 → 계절 파일(승인된 시즌일 때만) → 지역 파일 → common 순으로 찾아 `assets/scenes/`에 복사. **승인 없는 시즌은 기존 `applied.json`(approved_by/at 필수) 규칙 그대로 무시** → 자동 공개 없음, 연 4회 수동 승인.
- 미리보기: 기존 `AIRANG_SEASON=spring python3 app/build.py` 로컬만.
- 사진 규칙(029·033 동일): AI 생성, 글씨·로고·캐릭터·간판 없음, 랜드마크 실루엣·원경, 실존 인물 아님, 'AI 생성 이미지' 표기, 7항목 자체 검수, 재생성 1회, `docs/이미지_관리표.md` 기록.
- 지역 특색 장면(안): 부산 바다·다리 원경 / 대구 강·탑 / 광주 호수·공원 / 울산 강·대나무숲 / 제주 돌담·바다 / 창원 벚꽃길·호수 — 모두 '가족 + 풍경 원경' 구도로 통일.
