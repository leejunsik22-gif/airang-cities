# 아이랑 자동 화면 검사 (개발용 · 무료 Playwright)

운영 배포와 무관합니다. 앱은 package.json 없이 그대로 동작합니다.

## 처음 한 번
    npm ci
    npx playwright install chromium

## 실행
    npm run qa            # 대전 5개 구 · 폰 360/390/430 · 48개 검사
    npm run qa:report     # 결과 화면(실패 화면·기록 포함) 열기

시험 서버(`tools/qa/serve.py`)가 자동으로 5개 구 + 입구를 임시 폴더에 만들어 띄웁니다.
검사 중에는 GoatCounter 방문 통계로 아무것도 보내지 않습니다(차단).

## 검사 범위(`tests/e2e/airang.spec.js`)
5개 구 진입·이동 / 확정 로고·한글 글꼴 / 사진 깨짐·화질·AI 표기 위치 / 학원 검색·학교급 유지 /
하단 메뉴·빠른 메뉴 터치 / 보류 자료 비공개(화면·검색·요청) / 뒤로가기·새로고침·오프라인

기존 화면 검사 60개(가로 넘침·깨진 이미지·44px·글자 넘침·JS 오류)와 하단 메뉴 가림 24개는
`tools/qa/legacy/`(v3qa.js·navqa.js, 로컬 8766 서버 기준) 그대로 보존 — 중복 작성하지 않음.

## 자동 판정 밖(실기기)
사진의 자연스러움·얼굴 표정, 실제 갤럭시의 글꼴·설치·뒤로가기·비행기 모드.
글꼴 서버가 막힌 환경에서는 글꼴 실제 로딩 검사가 '건너뜀'으로 표시됩니다.
